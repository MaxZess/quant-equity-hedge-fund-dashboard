## 📋 Project Overview

As a Business Administration student with a strong interest in auditing, financial reporting and data-driven decision making, I developed this dashboard to explore how modern audit procedures can be supported through analytics and visualization.

The dashboard helps identify potential risk areas within transaction data through automated testing procedures and interactive reporting.

---

## 🔍 Key Features

### 🚨 Duplicate Invoice Detection
Automatically identifies duplicate invoice numbers and highlights potential duplicate payments.

### ⚠️ Unusual Transaction Detection
Detects transactions with unusually high values based on statistical thresholds.

### 🔴 Risk Scoring
Assigns risk categories to transactions based on transaction value and potential materiality.

### 🏢 Vendor Analysis
Analyzes transaction volumes and spending patterns across vendors.

### 📊 Interactive Visualizations
Provides audit-focused dashboards and charts to support data-driven reviews.

### 📝 Executive Audit Summary
Summarizes key findings and potential risk areas identified during testing.
